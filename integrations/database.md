# 프로젝트별 DB MCP 연결 계약

“DB MCP”는 하나의 제품명이 아니다. 실제 DB 엔진·조직 권한·필요한 기능에 맞춰 선택한 서버의 정확한 이름·공급자/저장소·버전·transport·노출 도구를 개인 프로젝트 등록 자료에 기록한다. 기존 다른 프로젝트의 연결 별칭을 팀 공통 서버로 적용하지 않는다.

## 연결 전 정보

- 제품/프로젝트 ID와 DB 엔진·대상 서버/DB, 필요한 schema 및 조사 목적.
- 읽기 전용 계정 또는 그와 동등하게 강제되는 권한. 프롬프트의 “읽기만”으로 권한 경계를 대신하지 않음.
- 인증 방식과 개인 secret 저장 위치, 네트워크/TLS 정책.
- query 시간·행·반환 크기 한도, 개인정보/운영 데이터의 제외·마스킹.
- 공급자 공식 연결 문서와 실제 지원 작업. 설치·계정 연결은 개인 호스트 설정으로 수행.

암호가 포함된 연결 문자열·실제 .env는 공통 template이나 source 사본에 포함하지 않는다. 비밀을 제거한 설정 키 설명만 남긴다.

## 확인과 사용

먼저 schema metadata 같은 최소 읽기로 인증·대상·권한을 확인한다. 다음에 필요한 집계와 제한 표본을 조회한다. 행 상한만으로 복잡한 join/scan 부하가 해결된다고 보지 않는다. 전체 테이블 전수 조회·다른 DB 탐색·운영 쓰기를 자동 수행하지 않는다.

질의 조건·대상·관찰 시각·실제 결과/오류·부분 반환 여부를 보존한다. 실패/timeout을 “자료 없음”으로, mock 결과를 실제 DB 결과로 표시하지 않는다. 사용자가 원하는 현재 현황은 오래된 query cache로 확정하지 않는다.

DDL/migration/rollback은 설계할 수 있으나 실행 권한은 별도다. 소스 snapshot은 DB 데이터 백업이나 복원 기능이 아니다.
