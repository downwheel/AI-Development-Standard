# Context7 MCP Server — Upstash

확인일: 2026-09-21. Context7 공식 저장소는 MCP 문서 조회와 별도의 CLI+Skills 방식을 안내한다. 이 표준에서는 현재 호스트에 있는 MCP를 우선 사용하며 추가 설정은 각 사용자가 선택한다. [공식 저장소·연결 안내](https://github.com/upstash/context7)

## 개인 연결

공식 문서의 현재 client 연결 절차를 확인한다. remote MCP 주소는 `https://mcp.context7.com/mcp`다. API key는 개인 secret 설정에 보관하고 공통 Git이나 입력 예제에 실제 값을 넣지 않는다. 공식 안내의 설정 도구는 로그인·키 생성·Skill 설치를 수행할 수 있으므로 읽기 조회와 구분해서 실행한다.

연결 후 작은 공식 라이브러리 질문으로 현재 노출된 기능을 확인한다. `resolve-library-id`는 library 식별, `query-docs`는 해당 ID의 문서 검색 역할이다. 정확한 실제 input schema를 확인해 호출한다.

## 사용 기준

프로젝트의 실제 package/lockfile 버전과 구체적인 질문을 먼저 정한다. 확인된 library ID는 재사용하고 필요한 부분만 검색한다. 출처·적용 버전·관찰 시각·결정에 사용한 근거를 개인 산출물에 남긴다.

결과가 존재하지 않는 API를 증명하는 것은 아니다. 공식 원문과 설치된 타입/SDK로 대조한다. 공식 저장소는 community 자료의 정확성·완전성 등을 보장하지 않는다고 밝힌다. 민감한 소스·DB 원문·자격증명을 문서 검색 질문에 전송하지 않는다.

계정/쿼터/네트워크 문제가 있으면 구체적으로 표시하고 이미 가진 로컬 타입·공식 원문으로 가능한 부분을 진행한다.
