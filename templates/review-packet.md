# 검토 패킷 표시 항목

이 문서는 사용자에게 제시할 자료의 양식이다. 승인 기록 자체가 아니다.

## 대상과 범위

실제 review ID와 bundle/presentation digest를 조회하여 보여준다. Gate A는 조사+요구+시스템 설계다. 2.1 신규 run의 Gate B는 단위+그 단위를 참조한 테스트 계획+scope와 적용되는 환경/DB 계획 전체 pins다. `create_review`가 반환한 presentation의 내용을 정확히 제시한다.

## 이번 결정

해결할 문제, 이번판 변경, 승인 시 진행할 구체적 작업, 제외 범위를 설명한다.

## 자료와 검토 결과

바로 열 수 있는 문서/native 자료, AI findings와 해결 여부, 미확인·제약·실행하지 않은 검증을 제공한다.

Gate B에는 scope payload에서 자동 생성한 UI·백엔드·검사·설정 파일별 action/필수 여부/baseline 표, 계층별 합계, DB 객체/action/예상·최대 행 수와 실행 한도, 환경 역할/실제 관찰을 포함한다. 수작업 요약으로 정확한 범위표를 대체하지 않는다. 개인 인증 값은 넣지 않는다.

## 사용자 결정

실제 응답이 온 경우에만 승인/거절/변경 요청의 원문·출처·대상 일치 여부를 기록한다. 무응답·AI 통과·다른 버전의 승인을 전용하지 않는다. 뒤늦은 응답은 원래 review 대상으로 보존한다.

## 외부 도구 계약 확인

도구별 적용 단위·mode·필수 결과, 실제 호스트 준비도, 사용한 근거·차단·승인한 대안을 보여준다. Gate A/B와 실제 검증의 결과를 구분한다. 미적용에는 제품 범위 이유를, 미실행에는 실제 차단 이유를 적는다. browser/database의 필수 tool_checks와 첨부 출처/현재 실행 연결을 확인한다. 협조적 관찰 제출을 공급자 호출 인증으로 표현하지 않는다.
