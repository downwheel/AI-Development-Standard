# ppt-create

회사 발표자료를 실제 표준 PPTX의 사본에서 작성한다. 사용자가 지정한 내용·총 장수·수정 범위를 우선한다.

## 적용 범위

회사 보고·제안·기술 발표용 PowerPoint 작성 또는 회사 양식으로의 변환에 사용한다. 일반 PPT 요청도 별도 양식이 없으면 이 회사 표준을 기본으로 한다. 사용자가 다른 템플릿을 명시했거나 기존 자료의 문구만 고치려는 경우 회사 양식으로 강제 전환하지 않는다.

## 진행

1. 목적·청중·핵심 내용·장수·제공 자료를 현재 대화에서 확인한다. 이미 답한 내용을 다시 묻지 않는다. 결과에 중요한 누락만 묶어 질문하고, 자료에 있는 수치와 근거를 먼저 읽는다.
2. [작성 기준](references/PPT.md)과 [템플릿 사용 지도](references/template-map.md)를 읽는다. [실제 PPTX](assets/company-template.pptx)의 크기와 레이아웃을 확인하고 필요한 원본 장표를 렌더링해 본다. 전체 자료를 재구성할 때는 원본 전체를 확인한다.
3. 장표별 목적·핵심 메시지·사용할 예시 레이아웃을 간결하게 정한다. 제작 요청이면 바로 초안을 작성한다. 사용자가 구성을 먼저 승인하겠다고 한 경우만 그 지점에서 기다린다. 제품 개발용 설계 승인이나 티켓 분할 절차를 발표자료 제작에 추가하지 않는다.
4. 원본을 작업 사본으로 복사하거나 템플릿 보존을 지원하는 도구로 가져온다. 필요한 예시 슬라이드를 복제하고 기존 개체·문단 서식을 유지하며 편집한다. 마스터·레이아웃·로고·쪽 번호를 보존한다. 원본 템플릿과 설치된 스킬 자산은 덮어쓰지 않는다.
5. 예시 제목·챕터·날짜·담당자·수치·주석을 실제 내용으로 교체한다. 사용하지 않는 예시 장표와 빈 자리는 제거한다. 표·차트·업무 도해는 가능한 한 편집 가능한 개체로 유지하고 로고와 그림의 비율을 지킨다.
6. 최종 장표를 렌더링하고 원본과 비교한다. 글자 잘림, 겹침, 서체 대체, 번호·제목 불일치, 예시 문구 잔재를 고친다. 수정 범위 밖 장표도 의도치 않게 바뀌지 않았는지 확인한다. 구조 검사만 통과한 것을 시각 검수 완료로 간주하지 않는다.
7. 완성 PPTX를 실제 저장 경로로 전달한다. PDF·미리보기는 요청했거나 검토에 필요한 경우 제공한다. 확인하지 못한 서체·렌더링 등 사용에 영향을 주는 제약은 짧게 알린다.

## 도구와 저장

현재 Codex에 설치된 발표자료 스킬·도구가 있으면 템플릿 편집 지침을 읽고 함께 사용한다. 회사 시각 규칙은 이 스킬의 자산·참조 문서로 적용한다. 도구가 없으면 사용 가능한 로컬 PPTX 편집·렌더링 경로를 확인한다.

현재 호스트의 `team-skills.json`과 프로젝트에 연결된 Workspace를 따른다. 완성 PPTX·요청된 PDF는 `artifacts`, 렌더링·임시 작업 파일·검사 로그는 `results`, 별도 테스트가 필요하면 `tests`에 둔다. 사용자가 최종 저장 위치를 지정하면 검수된 결과를 그 위치에 전달한다. 제품 소스 폴더나 스킬 설치 폴더에 중간 산출물을 남기지 않는다.

## 호출 예

`$ppt-create 이 회의 내용을 회사 표준 양식의 대표님 보고용 PPT 6장으로 만들어줘. 표지 포함 6장이야.`
