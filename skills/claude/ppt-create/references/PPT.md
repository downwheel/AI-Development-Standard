# 회사 발표자료 작성 기준

`기술개발실_표준템플릿.pptx`의 마스터·레이아웃·로고를 사용하는 회사 발표자료 작성 기준이다. 문서의 반올림 좌표보다 PPTX의 실제 요소를 우선한다. 사용자가 별도 양식이나 규격을 명시하면 해당 요청을 따른다.

## 슬라이드 규격과 그리드

| 항목 | 기준 |
|---|---|
| 슬라이드 크기 | 약 27.52 × 19.05cm, 사용자 지정 가로형 |
| 실제 EMU | 9,907,158 × 6,858,000 |
| 좌우 본문 여백 | 1.26cm |
| 본문 폭 | 25.00cm |
| 단 간격 | 0.50cm |
| 2단 / 3단 / 4단 폭 | 12.250 / 8.000 / 5.875cm |

16:9나 4:3으로 자동 변환하지 않는다. 좌표 단위는 cm이며 원점은 슬라이드 좌상단이다.

| 영역 | y | 높이 | 용도 |
|---|---:|---:|---|
| 헤더 | 0.00 | 2.20 | 소주제 번호·제목, 챕터·발표 제목 |
| 핵심 메시지 바 | 2.20 | 1.44 | 해당 장표의 메시지 한 문장 |
| 본문 사용 영역 | 3.80 | 13.45 | 표·도해·비교·설명, 하단 17.25 이내 |
| 선택적 요약 바 | 16.05 | 1.20 | 핵심 결론을 짧게 정리 |
| 푸터 예약 영역 | 17.55 | 1.50 | 출처·주석, 쪽 번호, 로고 |

요약 바가 있으면 그 위 본문은 y=15.85 이내에서 끝낸다. 요약 바는 모든 장표에 강제로 추가하지 않는다.

## 헤더와 푸터

| 요소 | x | y | 폭 | 높이 | 정렬 |
|---|---:|---:|---:|---:|---|
| 소주제 번호 | 1.02 | 0.48 | 1.60 | 1.10 | 왼쪽 |
| 소주제 제목 | 2.70 | 0.56 | 12.50 | 0.98 | 왼쪽 |
| 챕터명 | 15.60 | 0.30 | 10.66 | 0.68 | 오른쪽 |
| 발표자료 제목 | 11.00 | 1.04 | 15.26 | 0.60 | 오른쪽 |
| 헤더 구분선 | 1.26 | 1.92 | 25.00 | 0.03 | — |
| 메시지 바 배경 | 0.00 | 2.20 | 27.52 | 1.44 | 전체 폭 |
| 출처·주석 | 1.26 | 17.72 | 10.50 | 0.95 | 왼쪽 |
| 쪽 번호 | 12.26 | 17.96 | 3.00 | 0.60 | 가운데 |
| 로고 | 23.66 | 17.98 | 2.60 | 0.527 | 원본 비율 |

- 좌상단은 `01.` 같은 챕터 내 소주제 번호와 제목이다. 챕터가 바뀌면 번호를 다시 시작한다.
- 우상단 챕터명은 목차·간지와 일치시키고, 그 아래 발표 제목은 표지 제목과 일치시킨다.
- 메시지 바 배경·로고·쪽 번호 위치는 레이아웃에서 상속한다. 슬라이드 위에 같은 요소를 중복 생성하지 않는다.
- 페이지 번호는 `slidenum` 필드를 유지한다. 순서 변경 후 PowerPoint에서 표시 번호를 확인한다. XML에 남은 필드 캐시 값을 고정 페이지 번호로 복제하지 않는다.
- 밝은 배경과 네이비 배경의 로고는 해당 원본 레이아웃의 이미지를 그대로 사용한다. 다시 그리거나 늘이지 않는다.
- 주석은 최대 두 줄로 정리한다. 긴 출처 설명은 발표자 노트로 옮기되 청중에게 필요한 조건은 장표에 남긴다.

## 표지·목차·간지·마무리

| 표지 요소 | x | y | 폭 | 높이 |
|---|---:|---:|---:|---:|
| 영문 보조 제목 | 1.26 | 4.20 | 12.90 | 0.80 |
| 파란 강조선 | 1.26 | 5.25 | 1.80 | 0.12 |
| 발표 제목 | 1.26 | 5.90 | 12.90 | 5.20 |
| 부제 | 1.26 | 11.20 | 12.90 | 1.00 |
| 기본 키비주얼 | 14.80 | 2.21 | 12.10 | 8.19 |
| 하단 네이비 영역 | 0.00 | 12.74 | 27.52 | 6.31 |

- 표지 제목은 흰 영역의 `ink` 색상이며 두 줄 이내로 구성한다. 제목·부제·날짜·발표자를 실제 내용으로 바꾼다.
- 영문 보조 제목은 자료 성격이나 프로젝트명을 짧게 표현한다. 하단에는 부서와 담당자를 표시한다.
- 제공 PPTX에 포함된 기본 키비주얼을 재사용한다. 다른 그림으로 바꿀 때는 원본 비율을 유지하고 폭 12.10cm, 세로 중심 약 6.30cm를 기준으로 맞춘다. 별도 선종별 이미지 묶음이 있다고 가정하지 않는다.
- 목차에 있는 챕터는 해당 간지와 연결한다. 짧은 자료나 일부 장표만 요청된 경우 목차·간지를 기계적으로 추가하지 않는다.
- 간지와 본문 제목, 목차 항목의 명칭·순서를 일치시킨다. 부록이 필요하면 마무리 전에 둔다.
- 마무리에는 부서·담당자·연락처 중 실제 제공된 정보만 넣는다. 빈 자리표시는 최종본에 남기지 않는다.

## 색상

| 토큰 | HEX | 용도 |
|---|---|---|
| ink | #1B2A41 | 제목·표 헤더·주요 글자 |
| navy | #0B2545 | 표지 하단·목차·간지 |
| primary | #0D5EAF | 메시지 바·기본 강조 |
| primaryDk | #005092 | 진한 파란 보조색 |
| sky | #298CEF | 보조 강조·라인 |
| sky50 | #CDE4FB | 요약 바·네이비 배경의 보조 글자 |
| teal | #18ADA6 | 개선안 등 의미가 있는 포인트 |
| orange | #F28F0C | 주의·리스크 등 의미가 있는 포인트 |
| gray | #8C9CAA | 캡션·푸터 |
| grayDk | #5A6B7B | 본문 |
| line | #E9ECEF | 구분선·테두리 |
| bgSoft | #F5F7FA | 표 교대 행·본문 보조 영역 |

본문 배경은 흰색, 메시지 바는 primary를 기본으로 한다. orange와 teal은 한 장표에서 최대 한 종류만 포인트로 사용한다. 표지에는 금색·주황·노랑 포인트를 추가하지 않는다. 형광 노랑과 순수 검정은 새 디자인에 사용하지 않는다. 차트 계열은 primary → sky → sky50 → gray를 우선하되 구분이 필요한 데이터에는 충분한 대비와 레이블을 확보한다.

## 서체와 크기

기본 서체는 `페이퍼로지`이며 영문·숫자가 섞인 일반 본문에도 사용한다. 큰 수치 강조에는 `Pretendard SemiBold`를 사용한다. 파일에 기록된 정확한 글꼴 이름과 굵기를 유지한다.

| 요소 | 서체 | 크기 | 색상 |
|---|---|---:|---|
| 표지 영문 보조 제목 | 페이퍼로지 5 Medium | 14pt | primary |
| 표지 제목 | 페이퍼로지 8 ExtraBold | 28pt | ink |
| 표지 부제 | 페이퍼로지 5 Medium | 12pt | grayDk |
| 표지 날짜 | 페이퍼로지 5 Medium | 13pt | sky50 |
| 표지 부서·담당자 | 페이퍼로지 7 Bold | 14pt | 흰색 |
| CONTENTS | 페이퍼로지 8 ExtraBold | 16pt | sky |
| 목차 챕터 번호 / 제목 | 페이퍼로지 8 ExtraBold | 30 / 20pt | sky / 흰색 |
| 목차 세부 항목 | 페이퍼로지 4 Regular | 10pt | sky50 |
| 간지 챕터 번호 / 제목 | 페이퍼로지 8 ExtraBold | 60 / 40pt | sky / 흰색 |
| 간지 세부 항목 | 페이퍼로지 4 Regular | 12pt | sky50 |
| 헤더 소주제 번호 / 제목 | 페이퍼로지 6 SemiBold | 24 / 18pt | primary / ink |
| 헤더 챕터명 | 페이퍼로지 8 ExtraBold | 11pt | primary |
| 헤더 발표 제목 | 페이퍼로지 6 SemiBold | 9pt | gray |
| 메시지 바 문장 | 페이퍼로지 7 Bold | 19pt | 흰색 |
| 본문 소제목 칩 | 페이퍼로지 6 SemiBold | 13pt | 흰색 |
| 카드 제목 | 페이퍼로지 6 SemiBold | 12pt | ink |
| 본문·표 본문 | 페이퍼로지 4 Regular | 10pt | grayDk |
| 표 헤더 | 페이퍼로지 6 SemiBold | 10pt | 배경에 따라 흰색 또는 ink |
| 큰 수치 | Pretendard SemiBold | 30pt | 의미에 맞는 강조색 |
| 수치 단위 / 설명 | 페이퍼로지 5 Medium | 13 / 9pt | 강조색 / grayDk |
| 요약 바 | 페이퍼로지 6 SemiBold | 11pt | navy |
| 캡션·출처·주석 | 페이퍼로지 4 Regular | 9pt | gray |
| 쪽 번호 | 페이퍼로지 5 Medium | 9pt | gray 또는 sky50 |
| 마무리 인사 | 페이퍼로지 8 ExtraBold | 32pt | 흰색 |
| 마무리 연락처 | 페이퍼로지 4 Regular | 11pt | grayDk |

9pt는 캡션·푸터 등 보조 정보의 하한이며 일반 본문을 줄이는 목표값이 아니다. 글이 넘치면 문장 축약·재배치·분량 조정을 먼저 한다. 화면 투사가 중심인 발표는 필요한 본문을 키우고 한 장의 정보량을 줄인다. 고정 장수 요청은 지킨다.

PPTX에는 글꼴 파일이 내장되어 있지 않다. 제작·검수 환경에 해당 서체가 있는지 확인한다. 서체가 없으면 임의 대체를 숨기지 말고, 내용·구조 작업은 계속하면서 최종 서체 검수의 제약을 보고한다. 글꼴 설치나 외부 배포 권한은 별도로 판단한다.

## 본문 구성과 문장

- 비교는 2단 또는 3단, 단계 흐름은 4단, 수치 강조는 수치형, 명세는 편집 가능한 표를 우선한다. 필요한 관계를 설명하는 도해를 사용하고 의미 없는 아이콘을 늘리지 않는다.
- 제목은 주제를 짧게, 메시지 바는 해당 장표의 의미를 완결된 한 문장으로 쓴다. 근거 없는 효과나 결론을 메시지로 만들지 않는다.
- 텍스트를 한 덩어리로 붙이지 않는다. 항목 간 간격과 시각적 위계를 확보하고 불릿의 길이·행 수를 실제 렌더링으로 조정한다.
- 표·차트·설명 도해는 가능한 한 편집 가능한 개체로 유지한다. 모든 내용을 이미지 한 장으로 평탄화하지 않는다.
- 템플릿의 예시 챕터·수치·날짜·검수 문구는 디자인 예시다. 사용자 자료의 사실로 재사용하지 않는다.
- 필요한 원자료가 없으면 관련 질문만 묶어 확인한다. 초안에 남긴 가정이나 자리표시는 최종본에서 해결하거나 미확정 범위를 명확히 표시한다.

## 제출 전 검수

- 요구한 내용과 총 장수, 목차·간지·본문의 순서가 맞는가?
- 템플릿 크기, 마스터·레이아웃, 로고 비율과 위치가 유지되는가?
- 헤더·메시지 바·본문·요약·푸터가 겹치거나 잘리지 않는가?
- 실제 서체와 굵기, 줄바꿈, 글자 크기가 맞고 읽을 수 있는가?
- 핵심 메시지가 한 문장으로 읽히며 본문의 근거와 일치하는가?
- 포인트 색상·표·차트가 내용을 쉽게 구분하게 하는가?
- 페이지 번호가 연속적이며 샘플 제목·날짜·담당자·예시 수치가 남지 않았는가?
- 모든 최종 장표를 렌더링해 확인했고 편집 가능한 요소가 유지되는가?

검사에 사용한 이미지·임시 파일·로그는 발표 내용이나 발표자 노트에 삽입하지 않는다. 최종 PPTX와 사용에 영향을 주는 제약만 전달한다.
