# 템플릿 사용 지도

## 실제 포함 파일

- `../assets/company-template.pptx`: 사용자가 제공한 기술개발실 표준템플릿 원본. 그대로 복사해 작업을 시작한다.
- `../assets/cover-preview.png`, `../assets/body-preview.png`: 표지와 3단 본문의 구조 확인용 이미지. 이 이미지를 완성 슬라이드로 붙이지 않는다. 미리보기 생성 환경에서 지정 서체가 확인되지 않았으므로 글꼴 모양의 기준은 PPTX다.

템플릿은 예시 11장, `MW_표지`, `MW_목차`, `MW_간지`, `MW_본문`, `MW_마무리`의 다섯 업무 레이아웃과 `DEFAULT`로 구성된다. 예시 장수는 새 자료의 필수 장수가 아니다.

## 복제할 예시 장표

번호는 PowerPoint 표시 순서다. ZIP 내부 XML 파일 번호와 다르므로 `presentation.xml`의 관계 순서로 확인한다.

| 표시 순서 | 내부 파일 | 레이아웃 | 용도 |
|---:|---|---|---|
| 1 | slide1.xml | MW_표지 | 표지, 기본 해양·AI 키비주얼 |
| 2 | slide2.xml | MW_목차 | 챕터와 소주제 목록 |
| 3 | slide3.xml | MW_간지 | 첫 챕터 구분 |
| 4 | slide4.xml | MW_본문 | 3단 비교·요약 |
| 5 | slide5.xml | MW_본문 | 2단 대비·설명 |
| 6 | slide7.xml | MW_본문 | 편집 가능한 명세 표 |
| 7 | slide10.xml | MW_간지 | 다음 챕터 구분 |
| 8 | slide6.xml | MW_본문 | 4단 프로세스 |
| 9 | slide11.xml | MW_간지 | 다음 챕터 구분 |
| 10 | slide8.xml | MW_본문 | 수치 강조와 설명 |
| 11 | slide9.xml | MW_마무리 | 마무리·연락처 |

본문 유형은 같은 `MW_본문` 레이아웃에 서로 다른 슬라이드 개체를 올린 예시다. 레이아웃 이름만 선택하면 3단·표·프로세스가 자동 생성된다고 가정하지 않는다. 해당 예시 슬라이드를 복제하고 내용에 맞게 편집한다.

## 편집 시 주의점

- 새 빈 파일에서 색만 흉내 내지 않는다. 원본 사본의 마스터·레이아웃·theme·미디어 관계를 유지한다.
- 텍스트 치환 시 문단·run 서식을 유지한다. 도구가 기본 서체로 초기화하면 해당 요소의 원본 서식으로 복구한다.
- 페이지 번호의 `slidenum` 필드와 레이아웃의 `sldNum` placeholder를 보존한다. 표지부터 연속 번호를 사용하되 사용자의 번호 지정이 있으면 따른다.
- 예시 장표 중 여러 포인트 색상을 동시에 보여 주는 색상 설명과 수치 예시는 색상 견본이다. 실제 발표 내용으로 바꿀 때는 PPT.md의 장표당 포인트 한 종류 규칙을 적용한다.
- 원본에 들어 있는 문구의 '유형 수', '제작 시간 감소', 과거 조사 통계는 발표 자료의 사실이 아니다. 제목·목차·본문·주석·발표자 노트에서 예시 잔재를 확인한다.
- 마스터·레이아웃을 유지하지 못하는 도구라면 다른 사용 가능한 편집 경로를 선택한다. 외형만 같은 이미지 변환 결과를 편집 가능한 표준 PPTX라고 보고하지 않는다.
- 로고·키비주얼은 PPTX 안에 포함되어 있다. 별도 선종별 표지 세트, 도해 라이브러리, 사용자 PC에 없는 후처리 스크립트를 전제로 하지 않는다.

## 실행 환경

PPTX를 편집하고 렌더링할 수 있는 현재 환경의 도구를 먼저 확인한다. Python이나 JavaScript는 실행 환경일 뿐, 설치된 것만으로 PPTX 편집·렌더링 기능이 보장되지는 않는다.

Codex의 발표자료 도구가 사용 가능하면 그 도구의 템플릿 편집·검증 지침을 함께 적용한다. 다른 환경에서는 설치된 PowerPoint 또는 기존 PPTX 도구로 사본을 편집하고 렌더링한다. 특정 호스트의 전용 API나 MCP가 모든 팀원에게 있다고 가정하지 않는다. 발표자료 원문을 외부 서비스로 전송하는 것은 별도 사용자 권한 범위에서만 한다.

렌더링이 불가능하면 PPTX 구조·텍스트·개체 검사는 진행하되 시각 검수 완료라고 보고하지 않는다. 지정 서체는 `페이퍼로지 4 Regular`, `페이퍼로지 5 Medium`, `페이퍼로지 6 SemiBold`, `페이퍼로지 7 Bold`, `페이퍼로지 8 ExtraBold`, `Pretendard SemiBold`다. 글꼴 파일은 이 패키지에 포함하지 않는다.
